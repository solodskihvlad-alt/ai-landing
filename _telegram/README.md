# NeuroHelp: публикации в Telegram

Канал: @ai_assistent_gaid. Бот: @neurohelp_posts_bot.

Два слота: 10:00 и 18:00 по Москве. GitHub может задерживать запуск.
Повторные попытки возможны до 12:00 и 20:00. Не более одного поста за слот.
Содержимое очереди публично, как весь репозиторий. Секреты и сведения клиентов сюда не добавлять.

## Подключение

В Settings → Secrets and variables → Actions → New repository secret создать
`TELEGRAM_BOT_TOKEN` и вставить токен из BotFather. Не помещать токен в файлы,
комментарии, сообщения или историю Git. Для проверки открыть Actions → NeuroHelp
Telegram → Run workflow → mode: check. Проверка не публикует сообщения.

## Очередь

В posts.json все первые тексты — черновики (`approved: false`). Только после
проверки владельцем поменять на `true`. Цена и время выхода не определяют
одобрение. `slot` — morning или evening. Выбирается первый одобренный и ещё не
использованный пост нужного слота. Идентификаторы уникальны и не переиспользуются.
Файл state.json хранит историю отправок. Не удалять историю ради очистки очереди.
Пустая очередь не вызывает отправку и не создаёт новые тексты автоматически.

## Отказы и повторы

Сначала фиксируется резервирование в Git, потом сообщение уходит в Telegram.
При неоднозначной сетевой ошибке статус остаётся sending: повторная отправка
блокируется, чтобы не дублировать пост. Проверить канал вручную. Если сообщение
действительно не появилось, владелец может снять соответствующие записи из
state.json после проверки. Не менять идентификатор поста, чтобы обойти блокировку.
Если финальное сохранение после отправки не прошло, резервирование также остаётся
в силе; исправить историю вручную по реальному результату.

## Остановка

Actions → NeuroHelp Telegram → меню ⋯ → Disable workflow. Также можно отозвать
токен через BotFather. После 60 дней без активности GitHub может отключить
расписание публичного репозитория; проверять состояние во вкладке Actions.

При ограничениях основной ветки запись истории может не пройти: отправка тогда
останавливается до sendMessage. Не ослаблять защиту автоматически.
